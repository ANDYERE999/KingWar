# KingWar: 2D战地步兵突击 (Battlefield 2D Demo)

基于 **Godot 4.7.2 Mono (C#)** 开发的 2D 战地风格俯视角步兵战术射击演示 Demo。融合了《战地》系列经典的突破模式（Breakthrough）与《逃离鸭科夫》式的鼠标动态瞄准射击手感。

---

## 🎮 核心系统与设计特色

### 1. 突破推进模式（波兰战役 3 大重镇依次攻克）
全长 5000px 的战术大地图，设有 3 个依次解锁的防御扇区（Sector），沿 **但泽 ➔ 波兹南 ➔ 华沙** 的波兰战役轴线推进：
* **[A] 但泽 (Danzig)**：波罗的海造船厂与港口滩头，码头集装箱堆场、可摧毁港口仓库与外围巡逻林地。
* **[B] 波兹南 (Poznan)**：大波兰要塞城堡，钢筋混凝土永备雕堡、两翼交叉火力混凝土掩体群。
* **[C] 华沙 (Warsaw)**：起义街区废墟与中央街垒，南北两片可摧毁废墟建筑与维斯瓦河西岸阵地。

**规则机制**：
* 攻方必须将当前活跃据点的占领进度推进至 100% 后，下一战区才会解锁。
* 占领成功后，攻方前线重生点向前推移，并额外获得 +35 兵力点数（Tickets）。
* 攻方成功占领全部 3 个据点即可取得战役大捷；若攻方兵力耗尽则防守方胜利。

### 1.1 可切换战场地图（演示条带 / 三城拼接战役 / 单城）

主菜单新增「选择作战地图」下拉框，共三类：

* **内置演示条带**：手写的 5000×1200 战术走廊，即上面那 3 座重镇。
* **★ 波兰战役：但泽 ➔ 波兹南 ➔ 华沙（三城拼接）**（默认）：把三张真实城市图沿进攻轴拼成一条 17600×5120 的连续战线，**每座城市只对应 1 个据点**，城市之间的连接处全部填充为平原；每城占领半径按该城城区规模单独计算（实测 415 / 445 / 526 px）。
* **单城: <城市名>**：任选一张生成地图作为完整战场（共 32 座城市可选）。

### 1.2 地形对移动的影响

| 地形 | 步兵 | 坦克 |
| :--- | :--- | :--- |
| 平原 / 积雪 | 全速 | 全速 |
| **河流** | 0.60x 减速 | 0.60x 减速 |
| **山地** | 0.50x 减速 | **无法通过** |
| 建筑 | 阻挡 | 阻挡 |

山地碰撞体位于车辆专用物理层，因此同一道山脊步兵能翻越（减速）、坦克过不去；河流不设碰撞，仅用减速表达涉水代价。

### 1.3 出生点：据点的连接处

攻守双方的出生点不再定在据点中心，而是定在**当前据点与相邻据点的连接处**（两个据点连线的中点）：

* **进攻方**：当前据点与**后方**据点的连接处（开战前的首个战区回落到集结基地）。
* **防守方**：当前据点与**前方**据点的连接处（最后一个战区回落到后方基地）。
* 出生点会自动吸附到最近的**可通行**地面，不会生成在河流 / 山体 / 建筑里；同波单位带随机抖动，不会堆在同一点。
* 进攻方会被自动推离隔离墙 70px，避免卡在停战屏障碰撞体里。

生成地图的战场由 `MaskBattlefieldMap` / `CampaignBattlefieldMap` 搭建，与手写条带共用同一套游戏逻辑：

* 扇区边界由实际据点位置推导，不再硬编码；出生点、小地图、停战隔离墙均跟随地图尺寸。
* 可摧毁建筑被打掉后会从障碍列表移除，AI 随即不再绕行。
* **可摧毁建筑可被全部武器打爆**：步枪/机枪（射线）、火箭弹与手榴弹（圆形范围查询）、坦克主炮均可摧毁（默认 250 耐久）；不可摧毁建筑完全免疫。建筑块尺寸有上限，不会合并成长墙。
* 1024px 的数据掩膜会先降采样到 160 格（默认），否则世界会拉伸到 30000px 宽、生成 8000+ 建筑块而不可玩。

详细参数与添加流程见 [`aseets/assets_generation_pipeline/SEMANTIC_MAP_PIPELINE.md`](aseets/assets_generation_pipeline/SEMANTIC_MAP_PIPELINE.md)。

### 2. 逃离鸭科夫式射击手感
* **鼠标 = 射击落点**：枪口指向与弹道严格朝向鼠标所在的世界坐标。
* **动态镜头前瞻 (Lookahead)**：摄像机平滑朝鼠标瞄准方向延伸视野，提前探明远端敌情。
* **战术瞄准 (ADS / 右键)**：按住鼠标右键大幅收窄子弹散布，并拉远战术视野。
* **动态后坐力与准星散布**：移动、冲刺和连续射击会实时放大准星，停止射击后迅速恢复。
* **弹道与打击反馈**：支持子弹轨迹、跳壳、墙体火花、命中击中标记（Hitmarker X）、击杀流（KillFeed）。

### 4. 五款战术辅助装备

1. **战地医药箱 (Medkit)**：放置地面急救站，18秒内为半径140px内的友军持续大量恢复生命值。
2. **RPG-7 火箭筒 (Rocket Launcher)**：发射推进式高爆火箭弹，产生 180px 范围毁灭性轰炸，可炸毁木箱与沙袋掩体。
3. **补给弹药箱 (Ammo Box)**：部署弹药补给箱，持续为周围友军补充主武器弹匣备弹及火箭弹/手雷。
4. **M67 破片手雷 (Frag Grenade)**：延时反弹高爆手雷，遇墙壁与掩体反弹，专克室内死角。
5. **便携防弹沙袋 (Deployable Cover)**：朝鼠标方向瞬间构筑拥有 300 HP 耐久的防弹掩体。

### 5. 战役自定义与 AI 战术系统
* **主菜单设置**：
  * 可自由选择加入【进攻方】或【防守方】
  * 可自由设定 AI 士兵总数（6 至 48 人，默认 24 人 12v12 规模）
  * 可自定义进攻方兵力点数（50 至 300 点）
  * 可自选开局配备的武器与道具
* **战术 AI 行为树**：
  * 自动沿路线向当前活跃据点推进或依托掩体防守
  * 视线检测（Line of Sight Raycast）索敌
  * 依据武器类型进行战术点射与扫射，移动中规避火力
  * 残血时自动使用医药箱，遭遇掩体后敌军时掷雷/发射火箭
  * 阵亡后在友军后方据点波次重生

## 🕹️ 键位操作一览

| 按键 | 功能 |
| :--- | :--- |
| **W / A / S / D** | 角色移动 |
| **鼠标移动** | 准星与射击瞄准（镜头前瞻） |
| **鼠标左键** | 开火（全自动/半自动） |
| **鼠标右键** | 战术瞄准 (ADS / 收拢散布 + 放大视野) |
| **R** | 战术装填 / 换弹 |
| **G 或 Q** | 使用战术辅助道具（医药箱、火箭筒、手雷等） |
| **1 / 2 / 3 / 4** | 切换主武器（M4A1 / AK-74M / SVD / MP5） |
| **鼠标滚轮** | 快速切换上一款/下一款武器 |
| **左 Shift** | 战术冲刺（消耗耐力） |
| **E** | 载具登入 / 登出互动（靠近坦克按 E 上车/下车） |
| **M** | 左上角小地图放大 / 缩小 |
| **Esc** | 暂停 / 返回主菜单 |

### 战术小地图（左上角）

* 停靠在屏幕**左上角**，按实际战场长宽比绘制地形底图、据点占领圈与全部存活单位。
* 圆形光晕 = 该据点的真实占领半径；颜色跟随占领状态（黄 = 争夺中，蓝 = 已攻克，灰 = 锁定）。
* 白点 + 黄色朝向线 = 玩家本人；蓝点 = 友军；红点 = 敌军。
* 按 **M** 在常规尺寸与放大尺寸之间切换（放大后额外显示据点字母）。
* 小地图**不拦截鼠标**，不会挡住射击点击。

## 🛡️ 进攻方坦克装甲系统 (M1A2 主战坦克)

1. **装甲与弱点机制**：
   * 拥有 **1000 HP** 超厚重装甲。
   * **只能被火箭炮（RPG）伤害**：常规步枪子弹、冲锋枪子弹与破片手雷命中坦克时均判定为跳弹（0 伤害），并触发金属跳弹火花与音效；只有高爆火箭弹（DamageType.RocketExplosive）才能对其造成实质破坏。
2. **乘员席位与武器配置 (1-2 人乘员)**：
   * **主驾驶 (Seat 1)**：控制坦克机动履带移动（航速严格为步兵速度的 **0.9 倍** = 162 px/s），并操作 **120mm 榴弹主炮**（发射大威力高爆榴弹，具有广域 AOE 轰炸杀伤）。
   * **副驾驶 (Seat 2)**：操作 **12.7mm 重机枪**（430 RPM 高速穿甲扫射）。
   * **单人限制**：只有 1 人驾驶坦克时，**只能使用榴弹主炮**；只有第 2 名乘员上车后，重机枪才会被激活。
3. **玩家优先让座机制**：
   * 当友军 AI 驾驶坦克时，若玩家靠近并按 `E` 登车，**AI 主动让出主驾驶席位**转任副驾驶机枪手，玩家直接接管坦克主炮与移动驾驶权！
4. **据点动态刷新 (60 秒冷却)**：
   * 上一辆坦克被摧毁后，将开启 **60 秒** 重生倒计时。
   * 倒计时结束后，新坦克自动刷新在**进攻方打下的最新一个据点**后方（若尚未攻下任何据点则在进攻方集结基地就绪）。
